## 第一章：TD算法数学公式与物理含义

### 1.1 TD定义

**TD (Thermal Demand)** 表示热负荷需求，即空调系统需要消除（制冷）或补充（制热）的热量。

```
物理意义：让车内温度达到设定温度所需的热量/冷量
单位：W/℃ (每摄氏度对应的瓦数) 或 m² (等效得热面积)
```

### 1.2 TD完整数学公式

#### 1.2.1 总量公式

```
TD_total = TD_inner + TD_outer + TD_comfort + TD_sun + TD_defog + TD_other
```

#### 1.2.2 各分量公式

| 分量 | 数学公式 | 物理含义 |
|------|---------|---------|
| **内温TD** | TD_inner = (T_cabin - T_set) × K_inner | 车内温度与设定温度差产生的热负荷 |
| **外温TD** | TD_outer = (T_ambient - T_cabin) × K_outer | 车内外温差通过车身传热产生的热负荷 |
| **舒适性TD** | TD_comfort = f(T_set) | 设定温度对应的基础热负荷 |
| **日照TD** | TD_sun = Solar × Area | 太阳辐射通过车窗进入的热量 |
| **除雾TD** | TD_defog = f(T_ambient, RH) | 玻璃除雾时的额外热负荷 |

### 1.3 各分量详解

#### 1.3.1 内温TD (车内温度贡献)

```
TD_inner = (T_cabin - T_set) × K_inner

参数说明：
- T_cabin: 车内实际温度 (℃)
- T_set: 用户设定温度 (℃)
- K_inner: 车内温度对应子TD系数 (W/℃)

物理意义：
- T_cabin > T_set 时，TD_inner > 0，需要制冷
- T_cabin < T_set 时，TD_inner < 0，需要制热
```

**标定量**：
| 标定量 | 说明 | 来源 |
|--------|------|------|
| `CalModMgt_HVACMode_TinTd_Linrzd_Curve_X` | 车内头部温度 (℃) | TD相关 |
| `CalModMgt_HVACMode_TinTd_Linrzd_Curve_Y` | 室内温度对应子TD (W/℃) | TD相关 |

#### 1.3.2 外温TD (环境温度贡献)

```
TD_outer = (T_ambient - T_cabin) × K_outer

参数说明：
- T_ambient: 环境温度 (℃)
- T_cabin: 车内温度 (℃)
- K_outer: 环境温度对应子TD系数

物理意义：
- 环境温度高于车内温度时，外界向车内传热
- 环境温度低于车内温度时，车内向外散热
```

**标定量**：
| 标定量 | 说明 | 来源 |
|--------|------|------|
| `CalModMgt_HVACMode_ToutTd_Linrzd_Curve_X` | 环境温度 (℃) | TD相关 |
| `CalModMgt_HVACMode_ToutTd_Linrzd_Curve_Y` | 环境温度对应子TD (W/℃) | TD相关 |

#### 1.3.3 日照TD (太阳辐射贡献)

```
TD_sun = Solar_Radiation × Effective_Area

参数说明：
- Solar_Radiation: 日照强度 (W/m²)
- Effective_Area: 等效得热面积 (m²)

物理意义：
- 太阳辐射通过车窗进入车内产生热量
- 日照强度越高、进光面积越大，TD_sun越大
```

**标定量**：
| 标定量 | 说明 | 来源 |
|--------|------|------|
| `CalModMgt_HVACMode_TdLeSun_Linrzd_Curve_X` | 光照强度百分比 | TD相关 |
| `CalModMgt_HVACMode_TdLeSun_Linrzd_Curve_Y` | 主驾光照TD (m²) | TD相关 |
| `CalModMgt_HVACMode_LeSunCorre_Curve` | 日照修正（主驾） | TD相关 |
| `CalModMgt_HVACMode_SunTdCorByAmbT_Curve` | 环温修正日照TD | TD相关 |

#### 1.3.4 舒适性TD (设定温度贡献)

**标定量**：
| 标定量 | 说明 | 来源 |
|--------|------|------|
| `CalModMgt_HVACMode_ComTD_Curve_X_C` | 环温 (℃) | TD相关 |
| `CalModMgt_HVACMode_ComTD_Curve_Y_C` | 舒适性设定温度TD | TD相关 |

#### 1.3.5 除雾TD

**标定量**：
| 标定量 | 说明 | 来源 |
|--------|------|------|
| `CalModMgt_HVACMode_DefTaTd_Curve_X_C` | 前除霜时环境温度 | TD相关 |
| `CalModMgt_HVACMode_DefTaTd_Curve_Y_C` | 前除霜时修正TD | TD相关 |

## 第二章：春秋季标定方法与调参

### 2.1 春秋季工况特点

#### 2.1.1 气候特征

| 特征 | 描述 |
|------|------|
| 环境温度 | 15-25℃ |
| 日照变化 | 阴晴交替，林荫道/隧道频繁 |
| 湿度 | 相对较高，昼夜温差大 |
| 热负荷 | 较小但敏感 |

#### 2.1.2 核心矛盾

```
1. 热负荷敏感矛盾：外界15-25℃叠加日照，人体对微小温度变化极度敏感
2. 信号跳变矛盾：林荫道/隧道导致日照传感器波形呈方波跳变，易引发系统"抽搐"
3. 上下温差矛盾：头顶日照辐射，脚底底盘冷风，需要"头凉脚暖"
```

### 2.2 春秋季标定策略

#### 2.2.1 日照TD标定

**问题现象**：
- 进出林荫道时"忽冷忽热"
- 日照信号跳变导致TAO计算跳变
- 风门频繁切换异响

**标定方法**：

| 步骤 | 操作 | 标定量 |
|------|------|--------|
| 1 | 拉平日照修正曲线 | `CalModMgt_HVACMode_LeSunCorre_Curve` |
| 2 | 增加环温修正系数 | `CalModMgt_HVACMode_SunTdCorByAmbT_Curve` |
| 3 | 调整日照变化率限幅 | `SunUpLimIncRate_C` / `SunDownLimIncRate_C` |

**调整建议**：

```
CalModMgt_HVACMode_LeSunCorre_Curve 调整：
- X轴：光照强度测量值 (0-100%)
- Y轴：修正系数
  * 0-30%：维持线性小值
  * 30-70%：适当放大（补偿过渡季热负荷）
  * 70-100%：平滑处理，避免突变

CalModMgt_HVACMode_SunTdCorByAmbT_Curve 调整：
- X轴：环境温度 (℃)
- Y轴：修正系数
  * 15-20℃：较大修正（过渡季敏感）
  * 20-25℃：中等修正
  * >25℃：恢复标准修正
```

#### 2.2.2 内温TD标定

**问题现象**：
- 温度达到设定后波动大
- 忽冷忽热不舒适

**标定方法**：

| 步骤 | 操作 | 标定量 |
|------|------|--------|
| 1 | 调整车内温度TD曲线 | `CalModMgt_HVACMode_TinTd_Linrzd_Curve` |
| 2 | 增加迟滞控制 | `Mode_Hysteresis` |
| 3 | 调整变化率 | 内温变化速率限制 |

**调整建议**：

```
CalModMgt_HVACMode_TinTd_Linrzd_Curve 调整：
- X轴：车内温度 (℃)
- Y轴：TD系数 (W/℃)
  * 低温区(10-15℃)：适当降低系数，避免制热过度
  * 温和区(20-25℃)：平滑过渡，避免响应过快
  * 高温区(30-35℃)：增加系数，确保制冷效果
```

#### 2.2.3 外温TD标定

**问题现象**：
- 早晚温差大时温度控制不准
- 车内温度滞后

**标定方法**：

| 步骤 | 操作 | 标定量 |
|------|------|--------|
| 1 | 调整外温TD曲线 | `CalModMgt_HVACMode_ToutTd_Linrzd_Curve` |
| 2 | 优化过渡区斜率 | 使曲线在15-25℃区间平滑 |

**调整建议**：

```
CalModMgt_HVACMode_ToutTd_Linrzd_Curve 调整：
- X轴：环境温度 (℃)
- Y轴：TD系数
  * 15-20℃：适当提高灵敏度
  * 20-25℃：平滑过渡
  * 确保曲线在过渡区无拐点
```

### 2.3 春秋季典型标定参数

#### 2.3.1 推荐标定值

| 标定量 | 春秋季推荐值 | 说明 |
|--------|-------------|------|
| `CalModMgt_HVACMode_TinTd_Linrzd_Curve` | 15℃: 3, 20℃: 5, 25℃: 8, 30℃: 12 | 温和系数 |
| `CalModMgt_HVACMode_ToutTd_Linrzd_Curve` | 15℃: 4, 20℃: 6, 25℃: 8 | 适度响应 |
| `CalModMgt_HVACMode_LeSunCorre_Curve` | 平滑处理 | 避免跳变 |
| `SunUpLimIncRate_C` | 50-100 W/m²/min | 限幅 |
| `SunDownLimIncRate_C` | 50-100 W/m²/min | 限幅 |
| `Mode_Hysteresis` | 1.5-3℃ | 迟滞 |

#### 2.3.2 调试流程

```
Step 1: 静态标定
├── 不同环境温度点测试 (15, 18, 20, 22, 25℃)
├── 不同日照条件测试 (阴天/晴天/变化)
└── 记录TD计算值与实际响应

Step 2: 动态调试
├── 林荫道场景测试
├── 调整日照变化率参数
├── 优化风门切换逻辑

Step 3: 验证
├── 温度波动 < ±1℃
├── 无风门异响
└── 主观舒适度良好
```

## 第三章：冬季标定方法与调参

### 3.1 冬季工况特点

#### 3.1.1 气候特征

| 特征 | 描述 |
|------|------|
| 环境温度 | -20~10℃ |
| 日照 | 较弱，但雪地反光 |
| 湿度 | 干燥，静电多 |
| 热负荷 | 较大，需要制热 |

#### 3.1.2 核心挑战

```
1. 快速升温需求：用户希望尽快达到设定温度
2. PTC/热泵功率限制：低温下制热能力受限
3. 除霜需求：玻璃易结霜
4. 能耗控制：冬季续航敏感
```

### 3.2 冬季标定策略

#### 3.2.1 内温TD标定

**问题现象**：
- 升温太慢
- 达到设定温度时间长
- 车内温度分布不均

**标定方法**：

| 步骤 | 操作 | 标定量 |
|------|------|--------|
| 1 | 提高内温TD系数 | `CalModMgt_HVACMode_TinTd_Linrzd_Curve` |
| 2 | 调整上升速率 | `CMM_PassCbnTIncLim_C` |
| 3 | 优化目标水温 | `CalModMgt_HVACMode_TDtoWTCTout_Linrzd_Curve` |

**调整建议**：

```
CalModMgt_HVACMode_TinTd_Linrzd_Curve 调整：
- X轴：车内温度 (℃)
- Y轴：TD系数 (W/℃)
  * -10-0℃：较高系数 (15-20)，快速响应
  * 0-10℃：中等系数 (10-15)
  * 10-15℃：逐步降低，避免超调
```

#### 3.2.2 外温TD标定

**标定方法**：

| 步骤 | 操作 | 标定量 |
|------|------|--------|
| 1 | 调整外温TD曲线 | `CalModMgt_HVACMode_ToutTd_Linrzd_Curve` |
| 2 | 增加低温补偿 | 曲线在低温区提高系数 |

**调整建议**：

```
CalModMgt_HVACMode_ToutTd_Linrzd_Curve 调整：
- X轴：环境温度 (℃)
- Y轴：TD系数
  * -20~-10℃：高系数 (12-15)，补偿大温差
  * -10~0℃：中高系数 (8-12)
  * 0~10℃：中等系数 (5-8)
```

#### 3.2.3 目标水温标定

**问题现象**：
- 制热不足
- 水温上不去

**标定方法**：

| 标定量 | 说明 | 冬季推荐 |
|--------|------|---------|
| `CalModMgt_HVACMode_TDtoWTCTout_Linrzd_Curve` | TD→WTC目标出水温度 | 适当提高目标水温 |
| `CMM_tTgtPTCTempHilmt_Curve` | PTC水温限制 | 提高上限 |

**调整建议**：

```
CalModMgt_HVACMode_TDtoWTCTout_Linrzd_Curve：
- X轴：TD值
- Y轴：WTC目标水温 (℃)
  * TD < -100: 水温 55-65℃
  * TD -100 ~ -50: 水温 45-55℃
  * TD -50 ~ 0: 水温 35-45℃
```

#### 3.2.4 热泵边界标定

**标定方法**：

| 标定量 | 说明 | 冬季推荐 |
|--------|------|---------|
| `EMM_tHpPermitTeEvnLimtLow_C` | 热泵进入环境温度下限 | -10℃ |
| `EMM_tHpPermitTeEvnLimtLowDetaT_C` | 环境温度滞回 | 3-5℃ |

### 3.3 冬季典型标定参数

## 第四章：除雾逻辑标定与调参

### 4.1 除雾逻辑原理

#### 4.1.1 物理基础

```
起雾条件：玻璃温度 < 露点温度

露点温度计算：
Td = T - (100 - RH) / 5

其中：
- Td: 露点温度 (℃)
- T: 当前环境温度 (℃)
- RH: 相对湿度 (%)

示例：环境20℃，RH 80%
Td = 20 - (100-80)/5 = 20 - 4 = 16℃

当玻璃温度 < 16℃时，即会起雾
```

#### 4.1.2 三级除雾策略

```
┌─────────────────────────────────────────────────────┐
│  Level 4 (最高级) - 危险驾驶                        │
│  条件：RH > 85% 或 玻璃温度 << 露点                 │
│  动作：最大风量 + 强制除湿 + 报警                   │
├─────────────────────────────────────────────────────┤
│  Level 3 (高级) - 明显起雾                         │
│  条件：RH > 70% 或 玻璃-露点温差 < 3℃              │
│  动作：高风量 + 制冷除湿 + 开启AC                  │
├─────────────────────────────────────────────────────┤
│  Level 2 (中级) - 轻微起雾                         │
│  条件：RH > 55% 或 玻璃-露点温差 < 5℃              │
│  动作：中风量 + 适度除湿                           │
├─────────────────────────────────────────────────────┤
│  Level 1 (初级) - 预防                              │
│  条件：RH < 55% 且 玻璃-露点温差 > 5℃              │
│  动作：维持当前状态或低风量                        │
└─────────────────────────────────────────────────────┘
```

### 4.3 夏季除雾标定

#### 4.3.1 工况特点

| 特征 | 描述 |
|------|------|
| 环境温度 | 25-40℃ |
| 湿度 | 夏季暴雨时高湿度 |
| 起雾位置 | 前挡风玻璃内侧 |
| 原因 | 制冷导致玻璃温度低于露点 |

#### 4.3.2 标定方法

| 步骤 | 操作 | 标定量 |
|------|------|--------|
| 1 | 调整L3/L4触发阈值 | `CalCH_AutDef_TempDiff_T3/T4` |
| 2 | 优化风速曲线 | `CalCH_AutDefLvl3Fan_C` |
| 3 | 设置除湿强度 | 强制开启AC制冷除湿 |

**调整建议**：

```
夏季除雾标定要点：
1. L3触发阈值适当提高（更早介入）
   * CalCH_AutDef_TempDiff_T3: 5→6℃

2. L3风速适当提高
   * CalCH_AutDefLvl3Fan_C: 6→7档

3. 确保AC在除雾时强制开启
   * 检查除雾模式AC使能逻辑
```

### 4.4 冬季除雾标定

#### 4.4.1 工况特点

| 特征 | 描述 |
|------|------|
| 环境温度 | -20~10℃ |
| 湿度 | 车内人员呼吸产生湿度 |
| 起雾位置 | 前挡风玻璃内侧+外侧 |
| 原因 | 车内湿气 + 玻璃温度低 |

#### 4.4.2 标定方法

| 步骤 | 操作 | 标定量 |
|------|------|--------|
| 1 | 调整温度差阈值 | 考虑低温修正 |
| 2 | 设置PTC协同 | 除雾时提高PTC功率 |
| 3 | 优化除雾速度 | 提高风温 |

**调整建议**：

```
冬季除雾标定要点：
1. L3/L4阈值考虑低温修正
   * 环境温度 < 0℃时，可适当降低阈值

2. 除雾时目标水温提高
   * 进入除雾模式时，WTC目标水温 → 55-65℃

3. PTC协同控制
   * 除雾模式：PTC功率请求最大化
   * 退出条件：玻璃-露点温差 > 安全值
```

### 4.5 春秋季除雾标定

#### 4.5.1 工况特点

| 特征 | 描述 |
|------|------|
| 环境温度 | 10-25℃ |
| 湿度 | 昼夜温差大，易结露 |
| 起雾条件 | 夜间/清晨车内高湿度 |

#### 4.5.2 标定方法

| 步骤 | 操作 | 标定量 |
|------|------|--------|
| 1 | 调整触发灵敏度 | 平衡除雾与能耗 |
| 2 | 优化模式切换 | 平滑过渡 |
| 3 | 设置迟滞 | 避免频繁切换 |

**调整建议**：

```
春秋季除雾标定要点：
1. 触发阈值适中
   * CalCH_AutDef_TempDiff_T3: 4-5℃
   * CalCH_AutDef_TempDiff_T4: 2-3℃

2. 增加迟滞防止抖动
   * 进入L3: ΔT < 3℃
   * 退出L3: ΔT > 5℃

3. 风速适中
   * 避免过大风速导致不适
```

### 4.6 除雾调试流程

```
Step 1: 静态测试
├── 不同温湿度组合测试
├── 记录起雾临界条件
└── 验证触发阈值

Step 2: 动态测试
├── 模拟雨天场景
├── 模拟车内高湿场景
└── 验证响应速度

Step 3: 模式切换测试
├── 进入/退出平滑度
├── 迟滞控制效果
└── 退出后维持时间

Step 4: 主观评估
├── 除雾速度
├── 舒适度
└── 能耗影响
```
